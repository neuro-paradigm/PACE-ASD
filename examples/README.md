# PACE-ASD Examples

This directory contains example inputs and expected outputs for the PACE-ASD inference pipeline.

## Contents

- `input/` — Place example video files or pre-extracted `.npy` files here
- `expected_output/` — Reference outputs from a known checkpoint run

## Quick Start Example

### Using a pre-extracted .npy feature file (no video/MediaPipe required)

```bash
# Run inference on a pre-extracted subject
python scripts/infer.py \
  --input_npy processed/features/asd_1.npy \
  --checkpoint models/A1/fold1_seed42.pt \
  --config configs/inference.yaml \
  --output outputs/example_asd1
```

This produces:
```
outputs/example_asd1/
├── result.json            # Prediction probabilities and metadata
├── kinematics.npz         # Position, velocity, acceleration arrays
├── selected_events.json   # Salient temporal event blocks
├── attribution.json       # Body-region and kinematic-stream attribution
└── visualizations/
    ├── kinematics.png     # Position/velocity/acceleration trajectories
    ├── event_saliency.png # Block-ESG saliency scores
    └── evidence_summary.png  # Multi-panel evidence visualization
```

### Using a raw video file (requires MediaPipe)

```bash
python scripts/infer.py \
  --input path/to/video.mp4 \
  --checkpoint models/A1/fold1_seed42.pt \
  --config configs/inference.yaml \
  --output outputs/my_video_result
```

## Input Format

### Raw Video
- Format: `.mp4`, `.avi`, or any OpenCV-readable video
- Content: RGB video of a child walking/moving, recorded from a standard camera
- Length: ideally 5–15 seconds (longer clips are automatically truncated to 300 frames)

### Pre-extracted .npy (preferred for reproducibility)
- Shape: `(300, 33, 2)` float32 — MediaPipe 33-landmark sequences, hip-centred and shoulder-scale-normalised
- Generated by: `python src/preprocess.py --raw_dir <video_dir> --out_dir processed`
